# BeefTV Canvas

基于 [glanderness/BeefTV](https://github.com/glanderness/BeefTV) 的无限画布应用，支持 AI 图像生成。

## 快速开始

```powershell
cd F:/Canvas/BeefTV
.\run-local.ps1
```

访问 http://localhost:3000
